# Assignment 07: Final Project

## Goal

Use the guided core to accelerate a larger application or advanced pattern.

Good project choices are concrete and measurable:

- "Implement CSR SpMV and compare row distributions" is good.
- "Do graph stuff on GPU" is too wide.

## Deliverables

- Proposal: one page.
- Design doc: use [DESIGN_DOC.md](DESIGN_DOC.md).
- Code: CPU baseline, GPU implementation, tests, benchmark script.
- Report: use [REPORT_TEMPLATE.md](REPORT_TEMPLATE.md).
- Demo: 8-10 minutes.

## Suggested Timeline

- Week 8: proposal.
- Week 9: CPU baseline and first correct GPU kernel.
- Week 10: profiling and optimization plan.
- Week 11: optimized implementation.
- Week 12: stress tests and ablations.
- Week 13: report draft.
- Week 14: final demo.
