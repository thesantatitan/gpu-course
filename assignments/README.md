# Assignments

The guided core is six programming assignments plus a final project. The first six are designed to be done in order because each one reuses the performance reasoning from earlier weeks.

## Guided Labs

1. [Vector Add](01-vector-add/README.md): CUDA compile/run loop, host/device memory, one thread per element.
2. [Grids And Matrix Multiply](02-grids-matmul/README.md): 2D indexing, boundary checks, naive and tiled matrix multiply.
3. [Memory Performance](03-memory-performance/README.md): coalescing, shared memory, tiled transpose.
4. [Convolution And Stencil](04-convolution-stencil/README.md): 2D convolution, constant memory, halos.
5. [Histogram And Reduction](05-histogram-reduction/README.md): atomics, privatization, tree reduction.
6. [Scan And Merge](06-scan-merge/README.md): work-efficient scan and dynamic partitioning.
7. [Final Project](07-final-project/README.md): advanced application and report.

## Starter Philosophy

Starter files are intentionally complete around the edges and incomplete in the middle. They should compile before you edit them, but correctness will usually fail until the TODO kernels are implemented.
